# Validation Telemetry (`crvscience-wildfront-game` v3.4.1)

Deterministic headless empirical validation artifacts generated by running `cargo test -p wf_sim --test headless_validation` directly against the compiled Rust core schema, voxel engine (`wf_core`), and simulation/tournament engine (`wf_sim`).

## Test Protocols
1. **T1 (`t1_deterministic_hex_skirmish_replay_and_terrain_invariants`)**: Verifies axial hexagonal distance symmetry, terrain movement/bypass rules across all scenarios, and bit-exact FNV-1a replay state hash determinism across repeated Veteran-AI skirmishes.
2. **T2 (`t2_bio_faction_deck_cost_utility_and_round_robin_balance`)**: Audits the master card roster (`master_roster.ron`) cost-versus-EHP/DPS utility distributions across organism clades and runs a headless round-robin bio-faction AI tournament matrix written to `faction_balance_matrix.csv`.
3. **T3 (`t3_svo_64tree_raymarching_bounding_invariant_and_throughput`)**: Benchmarks 64-tree (`4x4x4` Brick64) sparse voxel octree (`SVO`) hierarchical DDA raymarching throughput while checking bounding-volume hit equivalence against dense voxel ground truth.

## Output Files
- `faction_balance_matrix.csv` — Headless AI round-robin matchup win rates, turn counts, and score differentials across bio-factions.
- `wildfront_validation_summary.json` — Consolidated telemetry metrics for T1, T2, and T3 (also mirrored to `app-preprints/releases/wildfront-hexagonal-ecological-tactics-validation-telemetry.json` in the parent monorepo).
